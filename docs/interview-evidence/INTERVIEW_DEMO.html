1. One-minute story (say this)

What I built: A multi-agent reliability + FinOps API on Azure Kubernetes. Alerts come in, LangGraph agents propose diagnosis / cost / remediation, a policy guardrail decides allow / require human approval / deny, and only then a dry-run executor runs. High-risk actions never auto-execute — they wait in /ui. Everything is audited.
